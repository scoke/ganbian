# 竿边 · 本机 Web 功能首版

这是在页面原型旁新增的真实本机记录入口，不替代共享 Expo 工程，不表示整套产品已完成。原型入口保持不变，两者不共享数据。

## 启动

仓库根目录运行 `python3 -m http.server 8094 --bind 127.0.0.1`，访问 <http://127.0.0.1:8094/local/>。无运行依赖、构建或云服务，不修改生产资源。IndexedDB 需要受支持的浏览器与允许网站存储；请始终使用同一地址、端口和浏览器，其他来源看不到此数据。

## 可使用的闭环

- 填写钓点、走水、选填实测水温；增加/移除竿并保存准备草稿。
- 明确选择每竿饵料、四类钓组及 1 / 1.5 / 2 / 3 / 4 小时间隔，缺项不能开始。
- 选饵带入常用间隔，之后手动选择优先。目录是三个初始示例偏好，不是对饵料有效期的科学结论；本版不含目录编辑。
- 统一配置应用前确认覆盖，空字段不清除单竿值。每竿可独立调整。
- 本机一场进行中，开始即各竿首次投饵。绝对时间保存，刷新后恢复；调整间隔不重置上次投饵，仅本竿换饵更新基准。
- 保存鱼获数量、鱼种与追加环境观察，手动结束后查看真实历史、汇总及起点走水筛选。未记录走水不等于基本不走，未称重不当作零。
- 本机事务成功后才显示保存成功；写入失败保留输入。多标签页以事务内版本检查拒绝覆盖过期数据，需保留输入并重新载入核对，不自动合并。
- 导出本机 JSON 备份；暂未提供导入恢复界面。

计时与覆盖规则经确认；暂停暂不实现。单场限制仅本浏览器，不能冒充服务端多用户约束。

## 提醒和数据边界

仅页面文字提醒，保存到期标记后提示一次，不播放声音或申请系统通知。改短后已到期会在下一次页面检查时提示；重复检查同一到期点不重复通知。到期状态持续到换饵或调整，不等于用户已换饵。浏览器后台、系统休眠会延迟检查；关闭页面不提醒，重新打开核对到期。不是原生通知验证结果。

数据只保存在本浏览器，未上传，无账号隔离、云同步、照片、真实天气潮汐、Electron/手机安装包或原型导入。清理网站数据会丢失记录，请定期导出。已有页面可断网记录，但没有离线启动缓存，不能承诺断网重新打开。修改跨账号、多端、登录、通知责任的规则仍需后续独立实现。
